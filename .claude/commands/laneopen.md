1. Read the work order file at repo root. If none exists: STOP, ask for one.
2. Restate, as text: the lane's mission, its write zone, its hard stops, and every done-when condition.
3. Confirm the locked fix order. If this lane's task is pulled forward out of order: REFUSE and route to strategy chat.
4. List what this lane will NOT touch.
5. State the first action and wait for approval. Do not start work in the same reply.
