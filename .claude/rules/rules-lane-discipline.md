# RULES — LANE DISCIPLINE
<!-- Destinations: ezra · Pegasus\pegasus · alexandras-properties · Exclusiva (each \.claude\rules\) · Loads: always -->

- Fresh session per lane. One lane, one job.
- Lane opens by reading the work order at repo root and restating its done-when conditions. No work order = ask for one.
- Locked fix order enforced at every lane open. Refuse pulled-forward backlog lanes.
- Flag ambiguity and stop. Business rules are never decided mid-build.
- A superseded ruling is a new stop point. Being right ≠ being authorized. Rulings are made once, recorded, not relitigated.
- Plain "Yes" (option 1) on every prompt. Never "don't ask again," never wildcards. Read-only approves freely; anything writing to git or a database is a full stop routed to strategy chat.
- Identical re-prompt three times = broken loop: press No, demand text output, restart the session.
- Bash output does not reach strategy chat on its own — file contents and commit messages are pasted as reply text.
- Wake-up rule: whatever is on screen, paste to strategy chat before pressing anything.
- Past ~10 hours or 3 AM: gates slip. Ship commands only after full packet review.
