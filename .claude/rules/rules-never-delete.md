# RULES — NEVER DELETE
<!-- Destinations: ezra · Pegasus\pegasus · alexandras-properties · Exclusiva (each \.claude\rules\) · Loads: always -->

- Nothing is ever deleted. No `rm`, no `git clean`, no overwrite-without-copy, no emptying files.
- Status flags hide. Provenance logs every mutation of history.
- Superseded files get `_superseded` in the name and stay.
- Moves are logged: MOVE_LOG.md (Documents) is the standard pattern — what, from, to, when, why.
- A tool or script that deletes as a side effect is flagged before it runs.
